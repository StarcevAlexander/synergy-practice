# Кейс-задача № 2 — Базовый и производный классы

**Условие.** Написать тестовую программу, которая демонстрирует работу методов
базового и производного классов.

## Что демонстрируется
- **Наследование** — `Car` и `Truck` наследуют `Vehicle`.
- **Вызов конструктора базового класса** через `super().__init__(...)`.
- **Переопределение метода** (`describe`) и обращение к базовой реализации через `super()`.
- **Полиморфизм** — один вызов `describe()` для разных объектов в общем списке.
- **Собственные методы** производных классов (`open_trunk`, `load`).

## Иерархия классов
```
Vehicle (базовый)
 ├── Car   — добавляет seats, open_trunk()
 └── Truck — добавляет capacity_t, load()
```

## Файлы
- `task2.py` — реализация и демонстрация (`demo()`).
- `test_task2.py` — автотесты.

## Запуск
```bash
python task2.py        # демонстрация
python test_task2.py   # тесты
python -m pytest -q
```
