# Кейс-задача № 1 — Обработка одномерного массива

**Условие.** Дан одномерный массив A размерности N. Найти сумму отрицательных
элементов, расположенных между максимальным и минимальным элементами.

## Файлы
- `task1.py` — реализация и интерактивный ввод.
- `test_task1.py` — набор автотестов.

## Запуск
```bash
python task1.py            # интерактивный режим
python test_task1.py       # прогон тестов
python -m pytest -q        # тесты через pytest (если установлен)
```

## Алгоритм
1. Находим индексы максимума `i_max` и минимума `i_min`.
2. Границы интервала «между» — индексы строго между `min(i_max, i_min)` и
   `max(i_max, i_min)`; сами крайние элементы не учитываются.
3. Суммируем элементы интервала, которые меньше нуля.

Сложность — O(N) по времени, O(1) по дополнительной памяти.

## Пример
Вход: `1 9 -3 4 -1 -7 2`
Максимум `9` (индекс 1), минимум `-7` (индекс 5). Между ними: `-3, 4, -1`.
Сумма отрицательных: `-3 + (-1) = -4`.
