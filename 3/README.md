# Кейс-задача № 3 — База данных «Туризм»

**Условие.** Спроектировать БД «Туризм» (перечень услуг, заказ туров и др.):
4–5 таблиц предметной области (3–4 справочника + 1 таблица переменной
информации), первичные ключи, связи через внешние ключи.

## Состав базы данных
| Таблица      | Роль                       | Первичный ключ | Внешние ключи |
|--------------|----------------------------|----------------|----------------|
| `countries`  | справочник стран           | `country_id`   | —              |
| `hotels`     | справочник отелей          | `hotel_id`     | → countries    |
| `clients`    | справочник клиентов        | `client_id`    | —              |
| `tours`      | справочник туров (услуги)  | `tour_id`      | → hotels       |
| `orders`     | переменная информация (заказы) | `order_id` | → clients, → tours |

Таблица переменной информации `orders` ссылается внешними ключами на
ключевые атрибуты справочников `clients` и `tours`.

## ER-схема (текстовая)
```
countries 1───∞ hotels 1───∞ tours 1───∞ orders ∞───1 clients
```

## Запуск
```bash
mysql -u root -p < schema.sql
```
Скрипт создаёт БД `tourism`, таблицы, ограничения, индексы, тестовые данные
и содержит примеры аналитических запросов (стоимость заказов, выручка по странам).

- `schema.sql` — полный SQL-скрипт (DDL + DML + примеры SELECT).
